How to read the wheel
The center is the shared vocabulary: the product of the wheels, the CRT map, survivors and admissibility. A node's ring is its longest chain of arrows back to a node that rests on no other node, so arrows always point outward. Solid line: a Lean-checked step. Dashed line: a planned one. Faint spoke: a ring-1 node whose claims use the shared vocabulary. Each wedge is one family. Click any node for its summary.
